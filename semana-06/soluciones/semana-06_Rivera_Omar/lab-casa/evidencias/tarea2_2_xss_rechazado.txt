PASO 2 — Intentar inyectar el mismo payload XSS:
  Solicitud: POST http://localhost:5002/comentario/nuevo
  Payload:   <img src=x onerror=alert(document.cookie)>
  Respuesta: HTTP 200 — {'mensaje': 'Comentario guardado'}

PASO 3 — Ver como aparece el comentario en /comentarios:
  Solicitud: GET http://localhost:5002/comentarios
  HTML fuente devuelto:

<html><body><h1>Comentarios</h1><div>Bienvenidos al foro seguro</div><div>&lt;img src=x onerror=alert(document.cookie)&gt;</div></body></html>

ANALISIS:
  XSS_ESCAPADO   = True   (debe ser True  — aparece como texto)
  XSS_EJECUTABLE = False  (debe ser False — no aparece como etiqueta)

  Payload original : <img src=x onerror=alert(document.cookie)>
  Payload en HTML  : &lt;img src=x onerror=alert(document.cookie)&gt;

  Encabezado Content-Security-Policy recibido:
    default-src 'self'; script-src 'self'
